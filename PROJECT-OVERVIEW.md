## Project Title
Continual Multi-Agent Workflow Orchestration

## Project Summary
Multi-agent systems coordinate the interaction of multiple agents to solve complex tasks. Recent advances in large language models (LLMs) have enabled agents to perform high-level reasoning and operate over structured workflows. A central problem in this setting is multi-agent workflow orchestration, where goals must be decomposed into interdependent tasks and coordinated across agents under evolving conditions and constraints.

This project studies continual multi-agent workflow orchestration, focusing on how a manager agent maintains coordination as tasks, dependencies, and agent populations change over time. We formulate this problem within a multi-agent reinforcement learning (MARL) framework, where agents act under partial observability and non-stationary objectives. The student will develop a prototype system that combines LLM-based reasoning for task decomposition with learning-based coordination, and design mechanisms that enable generalization across changing workflows without retraining.

The system will be evaluated in simulated multi-agent environments with dynamic task graphs, varying agent configurations, and shifting task requirements. The project provides hands-on experience in multi-agent systems, reinforcement learning, and LLM-based agent design through a focused study of adaptive coordination in evolving workflows.
